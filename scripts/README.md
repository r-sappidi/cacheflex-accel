# Legacy tools index

Paths stay stable for imports and frozen experiment manifests. This index groups
tools by role; it does not imply they are current or safe to execute. Check the
[agent guide](../AGENTS.md), [ledger](../docs/experiments/LEDGER.md) and live queues
before using launchers. New workload code belongs under `benchmarks/qwen/` or
`benchmarks/llama/`; shared scheduling helpers belong under
`benchmarks/infrastructure/`.
